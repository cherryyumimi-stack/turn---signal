## 在本機開啟與測試

1. 把整個 `turn-signal-site` 資料夾下載到電腦，**保持資料夾結構**（`css/`、`js/` 要跟 `index.html` 放在一起）。
2. 直接雙擊 `index.html`，用 Chrome、Safari 或 Edge 開啟即可，不需要伺服器。
3. 用手機測試：
   - 電腦的 Chrome 開發者工具（F12）→ 切換裝置模式，可以模擬手機畫面。
   - 要在真的手機上試，需要放到網路上（例如 GitHub Pages），再用手機開網址或掃 QR code。
4. 測試重點：
   - 按「開始聲音」才會出聲（瀏覽器規定）。
   - iPhone 請關閉靜音鍵並調高音量。
   - 換不同答案重做幾次，音色、音高、速度應該明顯不同。
   - 聲音頁按「下一頁」會看到音色、速度、音高、個人編號，以及感想問題。

## 問卷分數如何影響聲音

計分完全照規格：每題 0／50／100，三個維度各自取平均。

**一拍只響一下**，間隔完全固定（60 ÷ BPM 秒），沒有額外的聲音，也沒有隨機偏移。中間的燈在每次響起時亮起，半拍後熄滅。頁面上沒有拉霸，聲音完全由問卷決定。

| 維度 | 控制什麼 | 分數低 | 分數高 |
|---|---|---|---|
| 維持／改變 | **音色種類**（7 種） | 木頭 → 木琴 → 鈴鐺（熟悉、圓潤） | 撥弦 → 電子嗶 → 金屬 → 雷射（奇特、電子） |
| 靠近／退開 | 音高（對齊五聲音階） | 最多降一個八度 | 最多升一個八度 |
| 掌控／放手 | BPM | 慢，70 BPM | 快，120 BPM |

「維持／改變」有 3 題，平均分數剛好只有 7 種可能（0、17、33、50、67、83、100），每一種對應一個音色。

**個人差異：** 每個人的 A／B／C／D 答案組合（顯示為「編號」，例如 ABCDABC）會再微調：音高上下移一個音階、BPM ±4、餘韻長短、音色內部的質感（例如鈴鐺的泛音比例、雷射往上或往下滑）。所以分數相同的人，聲音也不會完全一樣；同樣的答案永遠得到同樣的聲音。

**現場同時播放：** 最低 70 BPM，不會和 60 BPM 的節拍器重疊；所有音色都有清楚的音高，和節拍器的「喀」聲容易分辨；音高對齊五聲音階，很多支手機一起響時比較和諧。

## 可以調整聲音特徵的地方

都在 `js/sound-mapping.js` 最上面的 `SOUND_CONFIG`：

| 想調整 | 改這個 |
|---|---|
| 音色的順序、名稱、基本音高 | `timbres`（`baseHz`） |
| 音高變化範圍 | `pitchRange`（半音，12＝一個八度） |
| 音階 | `scale` |
| BPM 範圍 | `bpmMin`、`bpmMax` |
| 個人差異大小 | `personalPitchSteps`、`personalBpm`、`decayMin`、`decayMax` |
| 最大音量上限 | `maxGain`（預設 0.9，後面有限幅器防爆音） |

每種音色的合成方式在 `js/audio-engine.js` 的 `VOICES`，一種音色一個函式；想加新音色，就在 `VOICES` 加一個函式，並在 `timbres` 加一行。

送到表單的「聲音數值」格式：`音色 鈴鐺，98 BPM，494 Hz（B4）｜編號 ABCDABC｜分數 靠近 50／掌控 75／改變 33`。

題目文字在 `js/questionnaire.js`，可以直接替換。**每個選項的 `score` 請保留**，計分就不會變。

## 收集回答（Google 表單）

網頁沒有伺服器，所以感想會送到你自己的 Google 表單，回覆會集中在表單的「回覆」分頁，也可以一鍵匯出成 Google 試算表。

1. 到 Google 表單建立一份新表單，新增兩題，題型都選「段落」：
   - 剛剛的聲音，你有什麼感覺？
   - 聲音數值
2. 在「設定」裡，**關閉**「收集電子郵件地址」和「僅限回覆 1 次」，這樣參與者不用登入就能送出。
3. 右上角「⋮」→「取得預先填入的連結」，兩題隨便填一些字，按「取得連結」並複製。
4. 把連結交給 Claude，或自己打開 `js/submit.js` 填入：
   - `formAction`：表單網址，把結尾的 `/viewform...` 換成 `/formResponse`
   - `fields.feeling`、`fields.summary`：連結裡兩個 `entry.數字`

還沒設定之前，按「送出」不會傳到任何地方，頁面也會直接說明這一點。
