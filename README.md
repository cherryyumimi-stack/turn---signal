## 在本機開啟與測試

1. 把整個 `turn-signal-site` 資料夾下載到電腦，**保持資料夾結構**（`css/`、`js/` 要跟 `index.html` 放在一起）。
2. 直接雙擊 `index.html`，用 Chrome、Safari 或 Edge 開啟即可，不需要伺服器。
3. 用手機測試：
   - 電腦的 Chrome 開發者工具（F12）→ 切換裝置模式，可以模擬手機畫面。
   - 要在真的手機上試，需要放到網路上（例如 GitHub Pages），再用手機開網址或掃 QR code。
4. 測試重點：
   - 按「開始聲音」才會出聲（瀏覽器規定）。
   - iPhone 請關閉靜音鍵並調高音量。
   - 拉霸移動時聲音應該慢慢變化、不會中斷。
   - 「初始聲音／目前聲音」可以切換比較。
   - 聲音頁按「下一頁」會看到初始／目前的速度、音高、音色，以及感想問題。

## 問卷分數如何影響聲音

計分完全照規格：每題 0／50／100，三個維度各自取平均。

聲音是**木頭敲擊聲**，像節拍器或木魚，**一拍只敲一下**，間隔完全固定（60 ÷ BPM 秒），沒有額外的聲音，也沒有隨機偏移。中間的燈在每次敲擊時亮起，半拍後熄滅。

| 維度 | 控制什麼 | 分數高 | 分數低 |
|---|---|---|---|
| 靠近／退開 | 音高 | 音較高，最多升 7 個半音 | 音較低，最多降 7 個半音 |
| 掌控／放手 | BPM | 快，最高 120 BPM | 慢，最低 70 BPM（50 分＝95 BPM） |
| 維持／改變 | 音色＋拉霸敏感度 | 乾、脆，像樹枝折斷；拉霸 100% 有效，約 0.35 秒跟上 | 悶、圓，像厚木塊；拉霸 50% 有效，約 1.5 秒跟上 |

**拉霸怎麼運作：** 進入聲音介面時，三個拉霸會放在問卷分數的位置（下方小三角形標示初始位置）。

- 第一個拉霸改變「靠近」分數。
- 第二個拉霸改變「掌控」分數，方向相反：往「交給偶然」拉，掌控分數就降低。
- 拉霸離初始位置多遠，會再乘上「維持／改變」的敏感度，才變成實際的聲音。
- 第三個拉霸本身就是「維持／改變」：往右拉，其他兩個拉霸的效果變大，聲音也變化得更快。

**初始聲音：** 只用問卷分數，不受拉霸影響。**目前聲音：** 套用拉霸。兩者切換時聲音會平滑過渡。在「初始聲音」模式下移動拉霸，會自動切回「目前聲音」。

## 可以調整聲音特徵的地方

幾乎都在 `js/sound-mapping.js` 最上面的 `SOUND_CONFIG`：

| 想調整 | 改這個 |
|---|---|
| 基本音高（木頭大小） | `woodHz`（720） |
| 木頭的「空心」感 | `modeRatio`、`modeLevel` |
| 悶／脆的餘韻長短 | `decaySoft`、`decayCrisp`（秒） |
| 悶／亮的程度 | `lowpassSoft`、`lowpassCrisp`（Hz） |
| 敲擊瞬間「喀」聲的大小 | `noiseSoft`、`noiseCrisp` |
| 樹枝折斷的細碎裂聲 | `crackleMax`（0＝不要） |
| 音高變化範圍 | `pitchRange`（半音） |
| BPM 範圍 | `bpmMin`、`bpmMax` |
| 拉霸敏感度範圍 | `sensMin`、`sensMax` |
| 聲音跟上拉霸的速度 | `glideSlow`、`glideFast`（秒） |
| 最大音量上限 | `maxGain`（預設 0.9，後面有限幅器防爆音） |

聲音的合成方式在 `js/audio-engine.js` 的 `voice()`（音色內插）和 `hit()`（一下敲擊）。

分數換成參數的公式在同一個檔案的 `TS.mapScoresToSound()`、`TS.currentScores()` 和 `TS.sensitivity()`。

題目文字在 `js/questionnaire.js`，可以直接替換。**每個選項的 `score` 請保留**，計分就不會變。

## 收集回答（Google 表單）

網頁沒有伺服器，所以感想會送到你自己的 Google 表單，回覆會集中在表單的「回覆」分頁，也可以一鍵匯出成 Google 試算表。

1. 到 Google 表單建立一份新表單，新增兩題，題型都選「段落」：
   - 剛剛的聲音，你有什麼感覺？
   - 聲音數值
2. 在「設定」裡，**關閉**「收集電子郵件地址」和「僅限回覆 1 次」，這樣參與者不用登入就能送出。
3. 右上角「⋮」→「取得預先填入的連結」，兩題隨便填一些字，按「取得連結」並複製。
4. 把連結交給 Claude，或自己打開 `js/submit.js` 填入：
   - `formAction`：表單網址，把結尾的 `/viewform...` 換成 `/formResponse`
   - `fields.feeling`、`fields.summary`：連結裡兩個 `entry.數字`

還沒設定之前，按「送出」不會傳到任何地方，頁面也會直接說明這一點。
